La méthode en bref

Tout se calcule modulo 7 : on ne garde que le reste de la division par 7. Le résultat donne le jour de la semaine :

Dans le jeu, dimanche est le bouton 7 ; ici il vaut 0 (7 mod 7 = 0).

jour = ( J + M + A + S − B ) mod 7
  • J : le quantième (1 à 31)
  • M : le code du mois
  • A : le code de l'année
  • S : le code du siècle
  • B : 1 si l'année est bissextile et que le mois est janvier ou février, sinon 0

1Le modulo 7

Retire des multiples de 7 jusqu'à obtenir un nombre de 0 à 6. Astuce : 7, 14, 21, 28 ne comptent pas.

  • 29 → 29 − 28 = 1
  • 32 → 32 − 28 = 4
  • 68 → 68 − 63 = 5

Tu peux réduire à chaque étape pour garder de petits nombres : la réponse reste la même.

2Le code du mois

033 614 625 035

À retenir par groupes de trois mois :

Repères : janvier = octobre = 0 · février = mars = novembre = 3 · avril = juillet = 6 · septembre = décembre = 5.

3Le code du siècle

Il suit un cycle de 4 siècles (400 ans), puis tout recommence :

Pour les années 1900 à 1999 → 0, 2000 à 2099 → 6, puis on descend de 2 à chaque siècle : 4, 2, 0, 6, 4, 2, 0, 6…

4Le code de l'année et les bissextiles

Prends les deux derniers chiffres de l'année (yy) :

A = ( yy + ⌊yy ÷ 4⌋ ) mod 7

⌊yy ÷ 4⌋ = combien de fois 4 entre dans yy (on ignore le reste). Exemple 26 : 26 + 6 = 32 → 4.

Année bissextile : modulo 4 = 0 (donc divisible par 4). Exception pour les années de siècle : 1900 et 2100 ne le sont pas, 2000 l'est (divisible par 400).

Si l'année est bissextile et que la date est en janvier ou février, retranche 1 au total (B = 1). À partir de mars, rien à corriger.

5Assembler : deux exemples

05.11.2026

  • J = 5 · M (novembre) = 3 · S (2000s) = 6
  • A : 26 + 6 = 32 → 4
  • Total : 5 + 3 + 6 + 4 = 18 → 18 mod 7 = 4 = jeudi

29.02.2024 (année bissextile, février)

  • J = 29 → 1 · M (février) = 3 · S = 6
  • A : 24 + 6 = 30 → 2
  • B = 1 (bissextile, février)
  • Total : 1 + 3 + 6 + 2 − 1 = 11 → 11 mod 7 = 4 = jeudi

La méthode fonctionne de l'an 1 à l'an 3000 (calendrier grégorien étendu vers le passé, comme dans le jeu).
